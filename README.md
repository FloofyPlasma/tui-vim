# tui-vim

Syntax highlighting and filetype detection for [tui](https://github.com/mjdave/tui) files, for Vim and Neovim.

## Installation

With [lazy.nvim](https://github.com/folke/lazy.nvim)

```lua
{
  "FloofyPlasma/tui-vim",
  ft = "tui",
}
```

Filetype detection applies to any `*.tui` files.
